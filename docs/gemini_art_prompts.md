# Battle Cows Gemini Art Prompts

Use the shared art direction at the start of every prompt. Generate each asset separately so the game can tint, animate, and layer it cleanly.

## Shared Art Direction

```text
Create an original game asset for Battle Cows, a playful hex-grid pasture strategy game.
Visual style: stylized 3D board-game art, chunky rounded shapes, expressive cartoon cows,
slightly exaggerated proportions, warm rustic farm colors, hand-painted materials,
soft cinematic lighting, subtle worn wood and pasture texture, polished mobile game quality,
friendly mischievous humor, strong readable silhouette, clear shape at small size.
Use the same visual language across the entire asset set: warm golden highlights,
deep brown outlines and shadows, grass green, hay yellow, mud brown, sky blue,
and red barn accents. Avoid realism, horror, photorealism, thin details, and visual clutter.
Composition must be centered, front three-quarter view, with the important feature facing
the camera. Leave clean breathing room around the silhouette.
```

## Shared Technical Instructions

```text
Create a clean game-ready asset, centered, isolated, transparent background,
no text, no logo, no watermark, no border, no UI, no extra objects,
consistent scale and camera angle, soft contact shadow only if requested,
high resolution, square canvas, PNG with transparency.
```

## Shared Negative Prompt

```text
photorealistic, realistic anatomy, horror, scary, aggressive gore, dark fantasy,
flat vector icon, anime, pixel art, human hands, duplicate limbs, extra eyes,
extra horns, cropped body, side profile, blurry, noisy background, text, letters,
numbers, logo, watermark, frame, multiple characters, unrelated props
```

## Generation Consistency Checklist

- Generate one reference Cowboy Cow first and use it as a style reference for the other cows.
- Generate all cow characters with the same camera height, canvas size, and shadow direction.
- Generate all board tiles with the same hex orientation and grass rim thickness.
- Keep characters and tiles separate from effects so animations can be layered in Flame.
- Ask Gemini for transparent PNG output whenever possible.
- Remove generated text, labels, and symbols that are not part of the requested object.
- Do not bake player colors into the base cow assets; apply team colors in the game.
- Export at 1024x1024 or larger, then create smaller optimized versions for mobile.
